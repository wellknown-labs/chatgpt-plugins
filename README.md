# Wellknown Workspaces for ChatGPT and Codex

Your consulting workspaces in ChatGPT and Codex: search a workspace's documents with citations,
run your firm's own playbooks, and check the claims of every answer.

> This repository is generated by [pluginpack](https://github.com/gleanwork/pluginpack). Please
> don't open pull requests against it; contact Wellknown instead.

Unlike the Claude plugin, this one carries its MCP connection: install the plugin and sign in when
prompted. There is no separate connector to add in the ChatGPT desktop app or Codex.

**ChatGPT web** treats a plugin that brings its own server as desktop only. On chatgpt.com, add
Wellknown Workspaces as a connector instead, with this URL:

```
https://mcp.wellknownlabs.com/v1/mcp
```

## For workspace administrators

1. In ChatGPT, go to **Admin → Plugins → Add → Import marketplace**, and enter this repository's
   URL.
2. Set **Wellknown Workspaces** to **Installed** for the roles that should have it.

## For individual users

```
codex plugin marketplace add wellknown-labs/chatgpt-plugins
```

Then install **Wellknown Workspaces** and sign in when prompted.

## The first time you use it

Ask anything about your workspace. The assistant connects to Wellknown Workspaces, and then:
1. You sign in.
2. You approve the assistant once on Wellknown's site.
3. In each conversation, you choose which workspace it may use.

## Network access for downloads

When Wellknown Workspaces hands the assistant a document to work on in code, its sandbox needs
network access to `mcp.wellknownlabs.com`. A plugin cannot allow-list domains: an administrator
does it in the host's settings.

- **ChatGPT and Codex cloud:** turn on internet access for the environment, and limit it to that
  domain.
- **Codex CLI and desktop:** allow network access in `config.toml`; an administrator can set or
  restrict it for everyone in `requirements.toml`.
